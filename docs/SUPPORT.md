# Support cod2.ts

If you enjoy this project and wish to support its ongoing development, tips are welcome via Ko-fi:

- **Ko-fi**: [ko-fi.com/skillman1337](https://ko-fi.com/skillman1337)

Tips are optional support for independent software development. They will not purchase Call of Duty 2, grant retail-content rights, unlock access, or guarantee particular features or completion dates. A wallet connection or payment is never required to play.

The most useful support is always a reproducible bug report, a focused contribution, or a documented compatibility test. Include the source revision, browser, relevant loading/cache state and reproduction steps. Do not attach retail assets, executables, private filesystem paths or wallet information. See [Contributing](../CONTRIBUTING.md) and [Compatibility](COMPATIBILITY.md).
